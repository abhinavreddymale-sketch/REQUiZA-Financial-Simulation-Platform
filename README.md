# REQUiZA (static build v4)
Open `index.html`, or run `python3 -m http.server` here and visit http://localhost:8000.
Font: save American Captain as `fonts/AmericanCaptain.ttf` (.otf/.woff2/.woff also work).
Tests: `npm test` runs engine acceptance tests T1-T10 with Node (no install needed).
Backend reference: `backend-reference/` (FastAPI). Progress is stored in this browser only (localStorage).
